# Roadmapa: etapy 0–17

Etapy są granicami zakresu i kryteriami odbioru. Etap 0 jest zakończony. Aktualny zakres to wyłącznie Etap 1: model domenowy, schematy Zod, fixture'y i testy. Dalsze etapy wymagają osobnych poleceń; obecność opisu nie uruchamia implementacji ani integracji. Etap 1 kończy lokalny commit bez push.

| Etap                              | Zakres                                                                                                                                             | Warunek zamknięcia                                                                                          |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **0. Fundament**                  | Osobne repozytorium, React / TS / Vite / Router / PWA / testy / Zod / lint / formatowanie, struktura modułów, pełny kontrakt, cztery ekrany shellu | Testy, typecheck, lint, build; jeden commit i push. Bez silnika                                             |
| 1. Kontrakt danych                | Pełny schemat Zod wersji 1.0.0, modele quizu / odpowiedzi / sesji, deklaratywne reguły, neutralne fixture'y                                        | Przykłady poprawne i błędne, stabilne ID, rozdzielenie prezentacji od wielu sposobów odpowiedzi             |
| 2. Import z raportem              | Parsowanie JSON, walidacja struktury i semantyki, liczby pytań / wariantów, referencje, wersje, błędy i ostrzeżenia                                | Raport przed decyzją; błędy blokują, ostrzeżenia wymagają potwierdzenia; brak cichej utraty pól             |
| 3. Lokalna biblioteka             | IndexedDB, zapis quizów i zasobów, ustawienia, wersje magazynu, biblioteka                                                                         | Przeżywa ponowne uruchomienie; błędy zapisu widoczne; brak kont i zależności od sieci                       |
| 4. Podstawowy silnik              | Czyste obliczenia, liniowa ścieżka, zatwierdzone decyzje, bez AI i UI                                                                              | Determinizm i neutralność treści potwierdzone testami; silnik nie importuje modułu AI                       |
| 5. Sesje i powrót                 | Trwały postęp, wznowienie, poprzednie pytania, edycja i „Wróć później” dla każdego pytania                                                         | Restart przywraca sesję; odłożenie i szkic nie są decyzją; błąd zapisu nie daje fałszywego sukcesu          |
| 6. Podstawowy ekran decyzji       | Pytanie, dowolna liczba wariantów, opis, zalety / wady / konsekwencje / wyjaśnienia                                                                | Mobile i desktop, klawiatura, brak eksponowania metadanych technicznych                                     |
| 7. Rekomendacja i wybór           | Rekomendacja autora i uzasadnienie, ustawienie widoczności, pomarańcz / zieleń / border / powiększenie                                             | Rekomendacja nigdy nie udaje wyboru; wybór jednoznaczny; ograniczony ruch i stany bez koloru                |
| 8. Sposoby odpowiedzi             | Pojedynczy / wielokrotny wybór, TAK / NIE, PRAWDA / FAŁSZ, tekst, skala, ranking, kombinacje                                                       | Wiele sposobów w jednym pytaniu; walidacja ograniczeń i brak limitu trzech wariantów                        |
| 9. Pytania wizualne               | Obrazy, powiększenie, porównanie, oceny, wiele wyborów, łączenie elementów i adnotacje                                                             | Nie trzeba wskazywać zwycięzcy; lokalne zasoby offline i opisy alternatywne                                 |
| 10. Jawna adaptacja               | Dodanie / modyfikacja / pominięcie pytania przez regułę; dziennik wyjaśnień                                                                        | Każda operacja pokazuje rodzaj, powód, regułę, wcześniejsze pytanie i odpowiedź                             |
| 11. Przeliczanie ścieżki          | Zmiana wcześniejszych decyzji, ponowne obliczenie, unieważnianie zależnych decyzji                                                                 | Brak niewidzialnych zmian; nieaktualne decyzje nie trafiają do aktualnej specyfikacji                       |
| 12. „Inne” i zatwierdzanie        | Szkic, analiza, interpretacja, skutki, „Zatwierdź odpowiedź” / „Zmień odpowiedź”; bez automatycznego zastosowania                                  | Decyzja wpływa na ścieżkę dopiero po potwierdzeniu; funkcje wymagające AI oznaczone, gotowy kontrakt modułu |
| 13. Raport i specyfikacja         | Kanoniczny pełny raport decyzji i wynikowa specyfikacja, kombinacje, historia zmian, nierozstrzygnięte kwestie                                     | Wynik z zatwierdzonych decyzji, bez dopisywania założeń i bez redukcji do A / B / C                         |
| 14. Eksport TXT / Markdown / JSON | Panel po „Eksportuj”, kolorowe pille, niezależny wybór formatów, „Generuj”                                                                         | Dopiero „Generuj” tworzy pliki; zgodność z raportem; czytelny stan aktywny / nieaktywny                     |
| 15. Eksport PDF                   | Lokalny PDF, polskie znaki, obrazy, wielostronicowy raport; dowolna kombinacja wszystkich czterech formatów                                        | PDF czytelny, spójny z raportem; brak wymogu połączenia AI lub serwera                                      |
| 16. Opcjonalny moduł AI           | Po wyraźnym zleceniu: osobny prywatny pośrednik, interpretacje i skutki, jawny zakres wysyłanych danych                                            | Brak klucza w PWA; awaria / offline nie blokuje zwykłego silnika; analiza nie zatwierdza decyzji            |
| 17. Stabilizacja i odbiór PWA     | Instalacja i aktualizacje, migracje, restart, scenariusze offline, mobile / desktop, dostępność, regresja                                          | Dowody z przeglądarki i telefonu; raport ograniczeń; pełny przebieg neutralnego quizu i eksportów           |

Zamknięcie Etapu 0 nie jest odbiorem gotowej aplikacji użytkowej. Etapy 1–17 są odłożone, a wdrożenie prywatnego hostingu pozostaje osobną decyzją.
