# Domena

Etap 1: `quiz.ts` definiuje schematy quizu, pytania, osobnej prezentacji, kompozycji mechanik, wariantów, rekomendacji, konsekwencji i reguł. `sesja.ts` definiuje odpowiedzi, decyzje, adnotacje, szkice, sesję i źródła zmian adaptacyjnych. Typy TypeScript pochodzą z `z.infer`.

Neutralne wobec treści, Reacta, magazynu i AI. Kontrakt i granice walidacji: `docs/FORMAT_QUIZU.md`. Bez importera, silnika, zapisu, integracji AI i schematu raportu.
